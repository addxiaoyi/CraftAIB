- Ubuntu 24.04 / WSL：`npm run typecheck:ui`、`npm run test:textures`、`npm run build:ui`、`npm run test:static-assets` 均退出码 0。日志在 `outputs/linux-acceptance/default-states-linux-*.log`；这些输出目录被 Git 忽略。

## 验收边界

- Lodestone 仍有 10 个上游未实现的可见特殊模型：`creeper_wall_head`、`dragon_wall_head`、`end_gateway`、`end_portal`、`piglin_wall_head`、`player_wall_head`、`shulker_box`、`skeleton_wall_skull`、`wither_skeleton_wall_skull`、`zombie_wall_head`。回归会明确锁定该名单，不把它们报告为已修复。

- 直接组装客户端的运行时下载曾在 `maven.fabricmc.net` 下载 `sponge-mixin` 时超时，真实日志位于本机忽略目录 `outputs/client-instance-1.20.1/runtime-prepare.log`。因此不得声称 Minecraft 游戏内验收通过。
- deepseek-flash 认证仍未更新，保留原 `MODEL_AUTH_FAILED` 证据，未重跑真实模型验收。

## 新设备

```sh
git clone --branch dev --recurse-submodules https://github.com/addxiaoyi/CraftAIB.git
cd CraftAIB
pnpm install --frozen-lockfile --ignore-scripts
npm run typecheck:ui
npm run test:textures
npm run acceptance:instance
npm start
```

本地页面：`http://127.0.0.1:4183/`。Minecraft 验收包位于 `outputs/client-instance-1.20.1/CraftAIB-Acceptance-1.20.1.mrpack`，游戏结果仍需在独立 Java 1.20.1 实例中填写 `outputs/client-acceptance/RESULTS.md` 的对应副本。
