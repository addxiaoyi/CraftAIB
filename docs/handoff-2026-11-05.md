## 新设备启动

准备 Node.js 24 或更新版本、pnpm 11.23.0 和 Git，然后执行：

```sh
git clone --branch dev --recurse-submodules https://github.com/addxiaoyi/CraftAIB.git
cd CraftAIB
pnpm install --frozen-lockfile --ignore-scripts
npm start
```

`npm start` 会先构建引擎、Worker 和前端，再在 `http://127.0.0.1:4183` 启动工作台。若使用 Codespaces，创建时选择 `dev` 分支。

完整验证需要先安装测试浏览器：

```sh
npm run setup:browser
npm run verify
```

Linux 缺少浏览器系统依赖时，使用 `pnpm exec playwright-core install --with-deps chromium --only-shell`。模型凭据没有上传；按 `.env.example` 在新设备本地配置 `.env`，不要把密钥写进聊天或 Git。
